- 📊 سیستم لول و امتیاز

## 🚀 نصب

pip install -r requirements.txt

## ⚙️ راه‌اندازی

1. توکن ربات رو از @botfather بگیر
2. یه فایل .env بساز و توش بنویس:
   BOT_TOKEN=توکن_خودت
3. ربات رو اجرا کن:
   python bale_bot.py
